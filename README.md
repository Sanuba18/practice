# TiendaCo: ¿dónde invertir marketing?

## Recomendación
Invertir en **reactivar y retener clientes**, priorizando Premium y miembros de lealtad.

## Hallazgos
1. **Las ventas cayeron 44%** desde el pico de jul-2024, no se estancaron.
2. **El 53% de los clientes no compra hace más de 90 días.** El problema es pérdida de clientes.
3. **35% de los Premium están inactivos.** Son el 15% de los clientes pero el 34% de las ventas.
4. **Los miembros de lealtad gastan 43% más por cliente**, aunque puede haber sesgo de autoselección.

## Próximos pasos
- Campaña de reactivación para Premium inactivos
- A/B test para validar el programa de lealtad
- Pedir datos de costos, márgenes y motivos de abandono

## Calidad de datos
Se eliminaron 50 duplicados, 40 cantidades negativas y 30 precios vacíos (~1% del total).
